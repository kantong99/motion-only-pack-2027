# Motion Only Pack 2027

Paket 10 motion graphic 4K (3840 × 2160, 30 FPS, 24 detik) **tanpa teks**. Fokus pada gerakan bentuk, grafik, dan transisi,
sehingga bisa dipakai sebagai latar, intro, atau B-roll untuk video apa pun.

## Daftar komposisi

| ID | Gerakan utama |
|---|---|
| M01-LogoMotion | Empat kotak terbang dari sudut, mengunci, lalu berubah bentuk |
| M02-BarRise | Batang grafik naik dan bernapas, garis tergambar, tiga cincin terisi |
| M03-StepFlow | Empat node, pulsa cahaya berjalan di garis dan menyalakan tiap node |
| M04-TimelineFlow | Garis bercahaya, kartu muncul bergantian, cahaya berjalan di jalur |
| M05-DonutShare | Donat berputar dan tumbuh, cincin orbit titik berwarna |
| M06-NetworkTree | Pohon node dengan sinyal yang mengalir di setiap sambungan |
| M07-ClickButton | Kursor klik tombol, ripple, lalu centang tergambar |
| M08-Waveform | Gelembung bicara dan gelombang audio yang berdenyut |
| M09-TargetHit | Tiga panah mengenai target, ledakan sinar keluar |
| M10-PhoneMotion | Ponsel miring dengan kartu meluncur, notifikasi melayang |

## Cara render

1. Buka **Actions > Render Motion Video > Run workflow**.
2. Ketik ID komposisi, misalnya `M01-LogoMotion`.
3. Pilih `preview` (1280 × 720) untuk cek cepat, atau `final-4k` untuk hasil akhir.
4. Unduh MP4 dari **Artifacts**.

## Upload ke GitHub

- Unggah seluruh isi folder proyek (termasuk `src/`).
- File workflow harus berada di `.github/workflows/render.yml` (folder bernama **workflows**, dengan s).
